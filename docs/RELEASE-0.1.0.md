# File Sync 0.1.0

首个独立单机源码版本。

提供Windows双击自动准备环境、安装镜像选择、SQLite免登录界面、多目录同步、比较/时间策略、临时发布、目标权限预检、实时状态、报告和全量日志查询。

包内仅包含单机程序、配置模板、文档、测试与安装工具，不含服务器管理模块、业务数据库、用户日志、虚拟环境或个人路径。

这是源码发行，需自行安装Python。Windows真实设备、网络共享权限、文件时间精度及长时间吞吐仍应按实际环境验证。没有多机Agent、远程调度、取消或大文件断点续传。

本地发布验证结果和远端CI结果请结合仓库Checks查看；工作流包含macOS/Linux单机回归以及Windows部署、API及启动冒烟检查。完整Windows文件系统验收不由冒烟测试替代。

## 发布前本地验证

在全新Python 3.12虚拟环境安装成功；90项单元/API回归通过；隔离数据库实际启动及健康版本检查通过；Chrome界面回归通过（包括报告筛选、跳页、实时动画和恢复状态）。测试均使用临时目录，没有迁入现有业务数据。
