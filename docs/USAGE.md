# 使用说明

## 创建任务

每组目录填写一个源、一个目标。同步源目录内的内容，不会额外套一层源文件夹。多个目录通过添加目录组配置。目录及父目录不能是符号链接；源目标不能互相包含。

新任务默认单向、仅大小比较、不删除多余文件。双向模式允许两侧互补，不传播删除，冲突默认保留。

## 比较和文件时间

仅大小速度快但无法识别等大小内容变化。大小＋修改时间接受0～60秒容差，默认2秒；SHA-256需要读取内容，成本更高。复制时默认保留源修改时间，已跳过文件不会改时间。时间使用绝对时间戳比较，不按操作系统手工加减时区。

## 权限、演练与重试

运行先检查全部目录组目标的读取和临时文件读写清理权限；双向检查两侧。目标不存在时检查最近已存在父目录，日志明确范围。预检通过不保证之后网络或磁盘状态不会改变。

演练不写目标文件，写入权限只做静态判断。实际同步遇到文件错误按配置重试；开启继续时保留失败记录并处理其他文件，安全边界错误仍停止。

## 进度、报告和日志

顶部状态跨页显示当前阶段、计数、速率与活动文件，每2秒刷新。总量未确定时不估算完成率。动画只表示运行状态，实际推进看计数和路径；连接中断暂停动画。

“最近报告”/“查看报告”显示已落库的复制字节和各动作数量。点击数字按对应状态筛选日志。失败/中断任务统计可能不完整，须结合错误核查；演练使用预计数量。

日志按状态、文件名/路径、目录组查询整次执行，支持50/100/500条每页、总数、排序和跳页。报告基于完整日志，不抽样校验或省略失败文件。执行记录界面目前仅列最近100次运行。

## 性能与边界

小文件使用有限线程池和批次，增加并发是否更快取决于磁盘/网络盘。大文件逐块写入，每文件不拆成独立分块任务，没有断点续传。日志批量提交，实时统计不逐块写数据库。

开启镜像删除会删除目标多余文件，应核对源路径。忽略项对应的目标内容受保护。默认忽略源链接/特殊文件；单向目标侧链接仍会触发保护停止。
