# 使用说明

## 创建任务

每组目录填写一个源、一个目标。同步源目录内的内容，不会额外套一层源文件夹。多个目录通过添加目录组配置。目录及父目录不能是符号链接；源目标不能互相包含。

新任务默认单向、仅大小比较、不删除多余文件。双向模式允许两侧互补，不传播删除，冲突默认保留。

## 比较和文件时间

仅大小速度快但无法识别等大小内容变化。大小＋修改时间接受0～60秒容差，默认2秒；SHA-256需要读取内容，成本更高。复制时默认保留源修改时间，已跳过文件不会改时间。时间使用绝对时间戳比较，不按操作系统手工加减时区。

## 权限、演练与重试

运行先检查全部目录组目标的读取和临时文件读写清理权限；双向检查两侧。目标不存在时检查最近已存在父目录，日志明确范围。预检通过不保证之后网络或磁盘状态不会改变。

演练不写目标文件，写入权限只做静态判断。实际同步遇到文件错误按配置重试；开启继续时保留失败记录并处理其他文件，安全边界错误仍停止。

## 进度、报告和日志

顶部状态跨页显示当前阶段、计数、速率与活动文件，每2秒刷新。总量未确定时不估算完成率。动画只表示运行状态，实际推进看计数和路径；连接中断暂停动画。

“最近报告”/“查看报告”显示已落库的复制字节和各动作数量。点击数字按对应状态筛选日志。失败/中断任务统计可能不完整，须结合错误核查；演练使用预计数量。

日志按状态、文件名/路径、目录组查询整次执行，支持50/100/500条每页、总数、排序和跳页。报告基于完整日志，不抽样校验或省略失败文件。执行记录界面目前仅列最近100次运行。

## 性能与边界

小文件使用有限线程池和批次，增加并发是否更快取决于磁盘/网络盘。大文件逐块写入，每文件不拆成独立分块任务，没有断点续传。日志批量提交，实时统计不逐块写数据库。

开启镜像删除会删除目标多余文件，应核对源路径。忽略项对应的目标内容受保护。默认忽略源链接/特殊文件；单向目标侧链接仍会触发保护停止。

## 多组目标与源目录名

每组的“包含源目录名”默认关闭：源 `/资料/照片` 到目标 `/备份` 时直接复制其内容；勾选后实际目标为 `/备份/照片`。预览会随路径选择更新，任务保存原目标和选项，运行日志记录实际目标。

多组可使用同一目标或父子目标，但仅限单向且关闭删除。目录组按列表顺序执行，同名文件按所选大小、时间或 SHA 比较与覆盖规则处理（并非一定由后组覆盖）。如需保留两组同名文件，请包含源目录名并确保源目录名称不同。开启删除或双向时各组实际目标必须独立，目标也不能覆盖其他组源目录。

## 暂停和运行中修改

在任务列表点击“暂停”，状态先变为“正在暂停”，完成当前文件并到达扫描检查点后变为“已暂停”。大文件或存储调用尚未返回时需要等待。点击“恢复”继续当前执行，不重新扫描已走过的部分。

暂停后从“更多 → 编辑任务”修改限速、重试次数/间隔、遇错继续和任务名称，保存后从后续文件生效。并发数、小文件批量和大文件阈值从下一目录组生效。已有目录组地址、顺序、包含目录名选项和同步规则锁定，允许追加新目录组。新目录会先进行权限检查。

暂停仍占用当前任务执行槽；关闭程序会中断任务并释放等待线程。重启后重新运行，使用比较规则处理已存在文件。执行日志可筛选“暂停 / 恢复”和“参数修改”。

## 网络中断与定时重试

在同步规则中勾选“遇到文件错误继续”，网络重试间隔默认 3 分钟、次数默认 3 次。断网、超时和存储 I/O 故障后先停止本组后续操作，等待正在执行的 I/O 返回；界面显示“等待网络重试”、原因、次数和倒计时。可以点击“立即重试”。次数用尽后保持暂停，检查网络后点击“恢复”；恢复开启新一轮计数。也可暂停期间修改网络重试参数。

每次网络重试重新扫描并比较当前目录组，已完成文件按比较规则跳过，不会重启已完成的前面目录组。普通权限错误不是连接故障，按普通文件重试/遇错继续规则处理；安全边界变化仍停止，不因重试而放开检查。操作系统尚未返回的阻塞 I/O 无法立即暂停。

## 扫描速度

界面扫描速率是源或目标已枚举条目数，不是文件复制速度。预检利用目录条目类型以减少网络属性请求；双向规划和复制前的属性检查仍然需要执行。配置内存预算和并行目录扫描尚未实现。

## 目录扫描策略（0.1.7）

“扫描与同步策略”在同步规则顶部。AUTO 保留原有大小/SHA/仅更新/双向行为；其他策略固定为单向，选项会显示并锁定对应语义。COMPARE_METADATA 使用大小和时间容差，MIRROR 额外删除多余目标；COPY_ALL 直接覆盖，SKIP_EXISTING 只看名称存在。

扫描并发与文件并发独立，默认扫描 1；先用实际挂载目录测试再增加。仅目录并发无法拆分一个超大目录，系统批量枚举才是该场景的优化。磁盘临时缓冲必须放在足够空间的本地临时目录；结束后清理，不保存历史索引。

结果报告和运行页显示扫描计数、调用数及队列；这些计数不代表真实网络数据包。原有逐文件日志可按复制/跳过/失败筛选。
