# File Sync 0.1.6

## 百万文件扫描

单向预检直接使用 scandir/DirEntry 的类型信息，不再逐普通文件 lstat。预检进度批量更新，空忽略规则直接跳过匹配，单向执行不再保存无用途的全量已见文件集合。复制前仍重新检查文件和路径，双向规划仍需读取两侧文件属性。

界面增加扫描条目/秒速率、当前目录和源/目标标记。源与目标仍需完整预检；此版未引入跳过安全检查、目录并行扫描或内存预算。

本机临时目录 2 万文件、100 个子目录、3 次中位数对照：0.1.5 预检 0.629 秒、20118 次 Path.lstat；本版 0.0281 秒、119 次 Path.lstat。基线使用当前公共辅助模块，此结果不代表 NAS 或实际复制速度；文件系统不提供条目类型时，DirEntry 内部仍可能查询属性。

复现：`python scripts/benchmark_scan.py --files 20000 --baseline-zip dist/file_sync-v0.1.5.zip`。不指定旧包时仅测试当前版，所有测试文件位于临时目录。

## 网络异常恢复

勾选“遇到文件错误继续”，配置网络重试间隔与次数。默认每 3 分钟重试，最多自动重试 3 次，之后保持暂停并提示管理员恢复。0 次表示遇到故障直接暂停。普通权限或单文件错误保留原处理规则，符号链接、路径边界失效等安全错误不自动重试。

重试会重新比较整个当前目录组，不恢复已失效的网络目录句柄；已完成文件按比较规则跳过。关闭程序会中断等待，重启后重新运行。重试过程中已有成功复制仍计入总数，历史错误和尝试均保留日志。
