# 单向大小比较与共享快照内存计划

1. 回归：AUTO 单向仅大小的同尺寸异时间文件通过快照跳过，禁止逐文件目标 stat；显式 COMPARE_SIZE 同语义；复制、镜像、混合文件保持正确。
2. 引擎：兼容条件路由至目录流水线，新增 NAME_TYPE_SIZE 字段等级，保留双向/SHA/updateOnly 原路径；目录已创建后不再为每个文件重复 mkdir。
3. 内存：所有扫描 worker 的目录快照共享可配置估算预算，耗尽落盘，关闭/失败释放预算。无需历史索引。
4. API/UI：保存预算、说明实际策略，配置协议升版防止旧后台忽略参数。
5. 全部测试、浏览器、针对大小快照的可复现基准、发布说明、独立打包、Git 推送及空闲时本机升级。

暂不更改持久性、日志架构、SHA/双向语义及线程上限。内存预算针对目录快照估算值，不是整个 Python 进程 RSS 硬限制。
